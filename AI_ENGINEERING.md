# AI-Assisted Engineering

DeliveryOS is developed through professional AI-assisted software engineering. AI accelerates implementation and review; it does not replace product ownership or deployment accountability.

## Human responsibilities

- Approve product scope, lifecycle semantics, privacy boundaries, providers, and architecture decisions
- Supply and secure external accounts, secrets, domains, billing limits, and production data
- Review migrations, concurrency behaviour, generated code, threat models, accessibility, and operational UX
- Approve test evidence, security posture, Mapbox licensing, observability policy, and production deployment

## AI-assisted responsibilities

- Translate the product brief into vertical slices and explicit interfaces
- Scaffold strict TypeScript, state machines, Zod contracts, Prisma models, workers, UI, and documentation
- Generate and expand unit, integration, concurrency, realtime, simulation, and E2E tests
- Review tenant scoping, state transitions, idempotency, race conditions, privacy leaks, and provider coupling
- Diagnose build/runtime failures, profile realtime rendering, suggest refactors, and keep architecture records aligned

Generated changes remain subject to normal code review. Delivery state semantics, tenant isolation, location privacy, migrations, and security-sensitive code require deliberate human approval.
